# THOKYO — GitHub Pages

## Publicar
1. Crie um repositório no GitHub chamado `thokyo`.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/thokyo/`.

## Observações importantes
- O caminho privado do vídeo de fundo foi removido. O site usa um fundo em gradiente até que você configure um vídeo com um link público direto.
- A música que já estava incorporada no HTML foi preservada.
- As edições feitas no painel Admin são salvas no navegador de quem está editando (armazenamento local). Elas **não atualizam automaticamente o site público para todos**. Para publicar alterações, baixe/substitua o `index.html` no repositório.
- O login do painel Admin é feito inteiramente no navegador. Não é uma autenticação segura para proteger dados ou funções sensíveis em um site público. Não coloque senhas, chaves de API ou dados privados nesse HTML.
